# Planos El Patrón

App web (carpeta `docs/`) para hacer planos de referencia de remodelaciones: cuartos, muros de tabla roca, techos de lámina, demolición, puertas y ventanas, instalación eléctrica, hidráulica y sanitaria.

- Se publica con **GitHub Pages** desde la carpeta `docs/` de la rama `main`.
- La nube, el agente y la voz natural usan Supabase.
- No contiene claves secretas (solo la clave pública de Supabase).
