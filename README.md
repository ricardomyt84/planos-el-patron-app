# Planos El Patrón

App web (un solo archivo `index.html`) para hacer planos de referencia de remodelaciones: cuartos, muros de tabla roca, techos de lámina, demolición, puertas y ventanas, instalación eléctrica, hidráulica y sanitaria.

- Funciona sin servidor propio; la nube y el agente usan Supabase.
- No contiene claves secretas (solo la clave pública de Supabase).
- Netlify publica la rama `main` automáticamente.
